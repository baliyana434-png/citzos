# Claude Anthropic Engineering & Design Skill

This skill brings Anthropic's official Claude 3.5/3.7 Sonnet & Opus system design, software engineering, and visual design standards directly to your development workflow.

## 1. Core Operating Principles

### A. Deep Architectural Reasoning & Direct Execution
- **Think Before Editing:** Trace dependencies, review data schemas, and understand the full system state before altering code.
- **Minimal, Surgical Diffs:** Modify only what is necessary to accomplish the objective. Never wipe out working functions or rewrite unrelated modules.
- **Preserve System Integrity:** Maintain backward compatibility with existing routes, session models, database stores, and type definitions.

### B. Anthropic Frontend Craft & Zero-Slop Standard
- **Ground Design in Subject Matter:** Every interface reflects the real materials, dignity, and domain of the product (e.g. sovereign gazettes, official registries, financial clarity).
- **Quiet Chrome:** Navigation, buttons, and backgrounds remain disciplined neutrals (graphite/slate). Avoid glowing borders, purple nebulas, and floating orbs.
- **One Memorable Moment:** Spend boldness in exactly one place (e.g. the swinging bell light on login, an authentic verification seal).
- **Exact Typographic Hierarchy:** Use weights 400 and 500, tabular figures for currency and counts, sentence case everywhere, and zero tracked-out all-caps labels.

### C. Verification Gates & Edge-Case Protection
- **Compilation Gate:** Run `npm run build` or typechecks after significant modifications. Ensure 100% of routes compile cleanly (exit code 0).
- **Security & Data Sanitization:** Validate and sanitize all user inputs, protect session tokens with httpOnly cookies, and prevent timing attacks or data leakage.
- **Responsive Ergonomics:** Ensure seamless layouts across 360px (compact mobile), 390px (iOS), tablet, and desktop without element collision or text truncation.
